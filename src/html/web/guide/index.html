Open the MASM editor

Online MASM compiler, linker and runner

WASM MASM x86 Editor is a free browser-based assembly editor. Write MASM-compatible source, assemble it with JWasm, link it with JWlink, and run the resulting 32-bit x86 executable in a BoxedWine terminal. Kip Irvine's Irvine32 library is included.

Launch the online MASM editor

Compile, link and run your first program

  1. Open the editor and wait for the terminal to finish loading. The first visit downloads the emulator and guest assets; later visits can reuse cached assets and a saved startup state.
  2. Select an .asm file in the file drawer, or create one. Replace its contents with the example below.
  3. Click the toolbar button labelled compile, link and run .asm file. It assembles, links and starts the selected program.
  4. Read the output in the terminal. Assembler and linker errors also appear there. After a successful build, run compiled binary runs the executable again.

Irvine32 example

This example prints a message using WriteString and Crlf:

INCLUDE Irvine32.inc

.data
message BYTE "Hello from MASM!", 0

.code
main PROC
    mov edx, OFFSET message
    call WriteString
    call Crlf
    exit
main ENDP
END main

Use INCLUDE Irvine32.inc for the bundled Irvine32 declarations. Additional bundled includes are Macros.inc, SmallWin.inc, VirtualKeys.inc and GraphWin.inc.

Which assembler and architecture does it use?

The tool uses JWasm and JWlink for MASM-compatible assembly and linking, not Microsoft's proprietary MASM executables. Although the assembler supports x86/x64 source, the browser's Wine execution environment is 32-bit; use 32-bit x86 programs with Irvine32. This is not a 64-bit Windows runner.

BoxedWine runs the Wine environment through WebAssembly. The editor and runtime require JavaScript and WebAssembly in your browser; you do not need to install an assembler or Wine locally. This guide itself works without JavaScript.

Where are my files saved?

Your files and settings are stored locally in your browser using IndexedDB and local storage. They are not a cloud backup and do not automatically follow you to another browser or device. Download copies of important files using the file menu before clearing site data or resetting storage.
